01 / Two Coefficients, One Question

Pearson ≠ Spearman

Pearson r

Linear association only. Sits at 0 for a perfect parabola. Sits at 0 for X vs X² when X is centered.

Spearman ρ

Rank-based. Catches monotonic curves. Robust to outliers. Lives in the order, not the magnitude.

r = 0.0     ρ = 1.0     same data, same answer, different question
