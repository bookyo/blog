02 / THE ZOO

Postcodes look universal. They are not.

Germany: 5 digits. UK: a six-position grammar that excludes the letters C, I, K, M, O, V. Japan: 100-0001 encodes a prefecture in the first three digits. Canada: letters in fixed positions. Argentina: a four-three split, with a province code up front and a district code in the back.

No two countries use the same rules. The Universal Postal Union has been meeting about it since 1874.
