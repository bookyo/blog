CARD 03 — REAL-WORLD PATTERNS

Three Globs That

Trip Production Code

src/**/*.js  → ^src/.*\.js$

!node_modules/**  → post-filter, not regex

data-202[0-3]-??.csv → ^data-202[0-3]-.{2}\.csv$

A mid-size JS project's node_modules holds 200,000+ files. The ** in !** is post-filter, not regex — mixing the two lints everything.
