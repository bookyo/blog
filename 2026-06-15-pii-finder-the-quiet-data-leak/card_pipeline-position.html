ARCHITECTURE

Four positions, four leak classes

Where the scanner sits in the pipeline decides what it catches

Pre-commit hook catches what developers remember. CI catches what's in the codebase. The log forwarder catches what's in production. The post-storage audit catches the regressions. The strongest pipelines use the last two together.
  • Forwarder + post-storage audit catches the steady state and the regressions
  • Pre-commit and CI each catch 60-70% of leaks that eventually reach production
  • Cheapest starting point: run the scanner against an existing log bucket today
