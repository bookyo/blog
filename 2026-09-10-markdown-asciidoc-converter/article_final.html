Migrating documentation from a Markdown repo to an Antora site (or the reverse) looks trivial in marketing copy, but the markup grammar between the two has just enough overlap to be dangerous: a # in source is a chapter in AsciiDoc, a [cols="1,1"] directive is invisible to GitHub, a [NOTE] blockquote and a NOTE: paragraph are spelled differently and parsed differently. The Markdown ↔ AsciiDoc Converter handles the 80 percent that's mechanical — heading promotion, link-bracket inversion, GFM pipe tables → |=== blocks, fenced code → [source] blocks, admonition blockquotes → NOTE: paragraphs — but the last 20 percent needs a human eye, and this field guide is the checklist.

Why Two Markup Grammars Exist At All

GitHub-Flavored Markdown was designed for README files: short documents, inline HTML allowed, headings by # count, links with the friendly text syntax. AsciiDoc was designed for books and reference manuals: long documents, no inline HTML by default, headings by = count (where the count is offset by the document level), links with the parser-friendly url[text] form. The two diverge most visibly in three places: heading promotion (every # needs to be re-counted when document nesting changes), tables (GFM pipe syntax vs |=== blocks with optional [cols] directive), and admonitions (Markdown blockquote convention vs AsciiDoc labeled paragraph). When you move a 200-page manual from one to the other, every one of those constructs needs a decision.

Five Constructs That Round-Trip Cleanly

The first set of constructs is what most teams think they're paying the converter for. These do round-trip cleanly: heading promotion respects the document-level offset, link brackets flip in both directions, fenced code blocks carry the language tag through [source,python], bold and italic survive because both grammars use the same inline spans, and unordered lists keep their bullet character. If your document is made entirely of these five, the converter is a copy-paste replacement.

In practice, however, almost no real document is made entirely of these five.
