OPTIMIZATION LEVELS

Level1 vs Level2

The difference between whitespace removal and CSS rewriting

LEVEL1 (BASIC)

  • Strips comments
  • Collapses whitespace
  • Removes trailing semicolons
  • Shortens color values

Lossless — no rendering difference.

LEVEL2 (ADVANCED)

  • Rewrites long-form values
  • Merges same-selector rules
  • Deduplicates declarations
  • Folds media queries

Saves another8–12%.
