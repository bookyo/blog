Fix today (15 minutes of work)

Headers with a one-line config change and zero application impact: X-Content-Type-Options: nosniff, Referrer-Policy: strict-origin-when-cross-origin, X-Frame-Options: DENY. These ship in a single PR.

Fix this sprint (a few hours of work)

A real CSP means an inventory of every inline script, every external CDN, every analytics pixel. The first time you do this, it will surface a script you forgot was there. That script is usually the bug.

Schedule and track (a quarter of work)

Strict-Transport-Security with preload requires submitting the domain to the HSTS preload list -- a deliberate process that touches every endpoint. Not a thing you turn on lightly.
