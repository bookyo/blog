Card 2 / The Three Debug Checks

Three checks that catch the bugs no one schedules

1. The misconfigured cache

A user sees a banner promoting a campaign that ended two weeks ago. The cause is almost always Cache-Control: max-age=86400 on a page that should be max-age=60. The analyzer reports what the browser and CDN are actually allowed to do with the response.

2. The CORS regression

A frontend deploy immediately starts seeing No 'Access-Control-Allow-Origin' header is present. The backend team swears they set the header. The analyzer shows the actual headers -- and the cause is usually a CDN stripping the header on cache miss, or auth middleware short-circuiting before CORS runs.

3. The redirect loop

A deployment moves a path and a typo in the redirect rule turns /old-page into a 302 to itself. The browser shows "too many redirects". The analyzer follows the chain and reports the exact hop where the loop closes.
