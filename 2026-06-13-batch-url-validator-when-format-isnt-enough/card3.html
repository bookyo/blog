Card 3 / The Throughput Math

Three rules for 10,000-row audits

1. Cap concurrent workers at 50

Beyond that, local port exhaustion and DNS resolver rate limits on shared resolvers start dominating. 50 is the practical ceiling for a home connection.

2. Use 5s connect, 10s read timeouts

Anything slower is almost always a dead host. Waiting 30s per dead host is what turns a 3-minute audit into a 30-minute one. The slowest 5% of the list dominates total runtime.

3. Separate the format check from the network check

A list of 50,000 URLs can be format-validated in 2 seconds. The network check should run on the format-valid subset. Interleaving them means format-invalid rows still consume worker time waiting for timeouts.
