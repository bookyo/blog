Card 2 / The Security Tells

Four patterns a format check cannot see

1. Open-redirect hosts

A ?redirect=https://attacker.com on a trusted domain is the most common phishing pattern on the open web. The URL parses. The destination is not the attacker's domain.

2. Punycode homograph domains

A domain that begins with xn-- is a Punycode-encoded IDN. Some are legitimate (German umlauts). Some are not: аpple.com (Cyrillic а) is registered attack infrastructure.

3. Mixed-scheme redirectors

A link that starts on https:// and follows a 302 to http:// has downgraded the transport. Format check passes. Security check flags the downgrade.

4. IDN homograph + lookalike TLD combos

A .com that is actually a Cyrillic confusable in a .cn IDN TLD. The string parses. The user sees apple.com and clicks. The resolver sends them somewhere else.
